# empezar

Carga también `~/.claude/CLAUDE.md` (reglas globales de versionado, skills y memoria).

## Qué es
La primera instalación de cada socio de Zoolutions Lab, publicada en https://zoolutionslab.github.io/empezar/ (GitHub Pages desde `main`, raíz). `empezar.ps1` (Windows, `irm … | iex`), `empezar.sh` (Mac, `bash <(curl …)`), `empezar.cmd` (Windows, fichero de respaldo, CRLF obligatorio), `index.html` (la página), `acceso/` + `.github/workflows/acceso.yml` + `invitaciones.json` (la palabra de invitación), `invitaciones.js` (genera las huellas), `docs/activar-acceso-automatico.md` (para Lucas). Todo en español de España; es público: nada secreto aquí.

## Estructura de `.claude/`
- `.claude/memory/MEMORY.md`: memoria del proyecto (decisiones, aprendizajes).
- `.claude/skills/<nombre>/SKILL.md`: skills de este repo, si surgen.
